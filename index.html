StudySync

A personal academic calendar synchronization tool.

About StudySync

StudySync is a personal software project designed to help organize university coursework by synchronizing assignment due dates with Google Calendar.

StudySync reads assignment information from the user's academic calendar feed and creates or updates corresponding events in the user's Google Calendar.

Google Calendar Integration

Google Calendar access is used only to create, locate, and update calendar events associated with StudySync.

StudySync does not sell user data or use Google Calendar data for advertising.
